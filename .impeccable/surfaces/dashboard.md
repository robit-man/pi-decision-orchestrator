# Dashboard direction

Mode: Operate. The user explicitly directed autonomous implementation of an operational Pi dashboard, so this work uses the complete supplied work order rather than pausing for a concept interview.

Grounded candidates: (1) topology control desk, (2) laboratory instrument panel, (3) transport dispatch board, (4) industrial PLC console, (5) airline operations queue, (6) workflow IDE, (7) observability workbench. The concept seed 1710bdab assigned candidate 7; it is the selected direction. Code-led implementation keeps this resource-constrained operational tool free of decorative raster assets.

First viewport: a narrow, permanent navigation column; a compact system status strip; the actual workflow and execution list taking most of the viewport; a quieter resources and model-residency column. A first-time installation shows a useful onboarding sequence and real empty states instead of invented executions. Desktop supports scanning while mobile stacks content in task order.

Signature interaction: one execution trace links validated input, inference, policy, and action states to full option-distribution bars. The graph editor uses the same workflow data and graph positions as the guided form. Color denotes state and node kind, never calibrated correctness.

Visual world: restrained observability console, humanist UI typography, tabular measurements, slate navigation, cool near-white working surfaces, cobalt actions, and explicit green/amber/red semantic status. Dark mode preserves roles. No decorative glow, hero metrics, false live data, or purposeless motion. Actual graph geometry uses SVG; drag-and-drop has form alternatives.

Challenger verdicts: split-flap board competitive on scanability but weaker on editing; streaming wall declined (raise: clear active selection); transit diagram competitive on branch clarity (raise: preserve path context); marketing monochrome declined (raise: spare secondary surfaces); boarding board competitive on persistent row identity; catalog sleeve declined (raise: disciplined measurement typography). The observability workbench remains the most legible match for operational decisions and dense configuration.
